PREPROCESSING

These functions load and clean the raw coral cover and microplastics datasets before analysis. The coral function filters the dataset to include only hard coral observations, converts relevant columns to numeric values, and removes incomplete records. The microplastics function similarly filters the data to samples collected in the Coral Sea, converts concentrations and latitude to numeric values, and removes invalid entries. Together, these steps ensure that only consistent, usable data are passed into the model for estimating region-specific initial conditions.

def load_coral_data(path):
    """Load and clean AIMS coral cover data."""

    # Read the coral cover dataset from the CSV 
    df = pd.read_csv(path)

    # Keep only rows corresponding to Hard Coral 
    df = df.loc[df["GROUP_CODE"] == "Hard Coral"].copy()

    # Convert coral cover values to numeric, making invalid entries NaN
    df["COVER"] = pd.to_numeric(df["COVER"], errors="coerce")

    # Convert latitude values to numeric, making invalid entries NaN
    df["LATITUDE"] = pd.to_numeric(df["LATITUDE"], errors="coerce")

    # Drop rows with missing coral cover, latitude, or year information
    df = df.dropna(subset=["COVER", "LATITUDE", "YEAR_CODE"])
    return df


def load_microplastics_data(path):
    """Load and clean marine microplastics data for the Coral Sea."""

    # Read the microplastics dataset from the CSV 
    df = pd.read_csv(path)

    # Keep only samples collected in the Coral Sea
    df = df.loc[df["Region"] == "Coral Sea"].copy()

    # Convert latitude values to numeric, making invalid entries NaN
    df["Latitude"] = pd.to_numeric(df["Latitude (degree)"], errors="coerce")

    # Convert microplastics measurements to numeric, making invalid entries NaN
    df["Microplastics"] = pd.to_numeric(df["Microplastics measurement"], errors="coerce")

    # Drop rows with missing latitude or microplastics measurements
    df = df.dropna(subset=["Latitude", "Microplastics"])
    return df

We created an annual time-series visualization of hard coral coverage between the years of 2005 to 2023. Hard coral coverage of coral reefs refers to the amount of live coral that can be detected and seen on the coral skeletons. This time series was created by parsing through AIMS survey sites across the coral reefs. Parsing through this data removed all unnecessary data, such as spaces that did not have hard coral coverage. From this data, we then converted the cover values to numeric form and computed the mean coverage for each year’s survey. The plot for the time series shows the interannual variability in coral coverage and displays a summary of the long-term trends in coral health. Visualization aids in viewing the fluctuations between periods of recovery and decline. These periods of decline and recovery are so variable and fluctuate so greatly due to the conditions of the waters, such as temperature, bleaching events, disease, and cyclones.

The assign_gbr_region function assigns each data point to a Great Barrier Reef region based on latitude, allowing coral and microplastic data to be grouped by geographic area. The safe_nonnegative function prevents numerical errors during model simulation by ensuring that coral cover and microplastic concentration never become negative. Together, these helper functions improve both the ecological interpretation and numerical stability of the model.

def assign_gbr_region(lat):
    """Assign a Great Barrier Reef region based on latitude."""
    # Northern Great Barrier Reef
    if lat >= -14:
        return "Northern GBR"

    # Central Great Barrier Reef
    elif lat >= -20:
        return "Central GBR"

    # Southern Great Barrier Reef
    else:
        return "Southern GBR"


def safe_nonnegative(C, P):
    """Ensure variables remain non-negative during integration."""
    return max(C, 0.0), max(P, 0.0)

The spatial visualization plot serves as a geospatial plot of the distribution of microplastic concentration in the Coral Sea. The data used for this analysis was also taken from AIMS using all available samples from different locations. Using the log transformation of the spatial visualization process improves the visibility and reduces skewness that occurred due to extremely high values. The areas with the most elevated concentrations appear in yellow dots. Using these plotted points, it is evident that the most heavy pollution occurs along the South Equatorial Current (SEC) and other associated eddies. The SEC and other eddies allow for the transport of microplastics and mass accumulation in the coral reefs. Through this spatial visualization, we can identify the geographic hotspots of microplastic abundance. However, there are a few major drawbacks to this model. Most of the samples were taken at or near the surface of the water, which is not the most reliable in terms of microplastic accumulation directly on the coral reefs. Another limitation is the amount of noise contained within these samples. With the consistent fluctuations and movements of the water, it is hard to obtain consistent results from the same places each time.
