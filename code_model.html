MODEL BUILDING

These two functions define the right-hand sides of a coupled ODE system for coral cover $C(t)$ and microplastics $P(t)$. The coral equation starts with logistic growth $rC(1- \frac{C}{K})$, a standard population-recovery model that captures rapid recovery at low cover and slowing growth as coral approaches a carrying capacity $K$. Logistic recovery models are widely used for coral cover dynamics, and in the Great Barrier Reef many researchers explicitly fit a logistic recovery framework to reef monitoring data and report an estimated carrying capacity around 80% for some non-stressful recovery periods [5].

Microplastics affect coral through the inhibition term $-{\alpha}PC$, which assumes microplastic stress increases with pollution level and impacts more coral when more coral is present. This is a simplified way to represent experimentally observed microplastic impacts on coral health and performance.

The microplastics equation $\frac{dP}{dt} = I - {\delta}P - {\beta}CP$ includes a constant input $I$, a first-order loss term δP which represents degredation, and an interaction loss term ${\beta}CP$ representing coral related trapping proportional to both coral cover and microplastic level. Finally, the with Allee model modifies coral growth by multiplying the logistic term by $(\frac{C}{A} -1)$, a classic strong Allee effect formulation that makes growth negative below a threshold A, reflecting recovery failure when coral cover is too low [6].

The coral population parameters K, which represents corals carrying capacity, and r, which represents corals intrinsic growth rate, were obtained from literature source [5]. This source measured and calculated the disturbance and dynamics of coral cover on the great barrier reef. They had a reported carrying capacity and intrinsic growth rate that we were able to utilize for simulation. The $\alpha$ parameter represents how strongly microplastics reduce coral growth, and was estimated because literature does not provide a single universal growth inhibition constant usable across reefs. Thus, it treated as an estimated or sensitivity parameter in this model, chosen to give realistic qualitative dynamics. This was an educated estimate with sources [7] and [8] used as a reference. The $\delta$ parameter represents the environmental degradation/export rate of microplastics per year. Marine plastics and microplastics are widely reported to be persistent and to degrade slowly in the environment with ranges from 100-1000 years for degredation [9]. For this model we aired on the optimistic side assigning a value for $\delta$ corresponding to 100 year degredation rates. The $\beta$ parameter represents coral reefs acting as sinks for microplastics, suggests reef building corals can remove a measurable fraction of bioavailable microplastics from reef waters each year. Although this number is small, recent papers have indicated that this value is worth measuring and was thus worth including in the differential equation systems. This value was estimated similarly to the $\alpha$ parameter using the sources listed below [10]. Additionally, the $A$ parameter represents the allee threshold which was obtained from the literature listed below [5]. Finally, the parameter $I$ represents the microplastic input rate which was calculated using mean surface microplastic concentrations and was scaled as described in the upcomming cells.

def coral_microplastics_no_allee(t, y, I, K, r, alpha, delta, beta):
    """Coral–microplastics ODE model WITHOUT an Allee effect."""
    # Unpack the state variables
    C, P = y
    C, P = safe_nonnegative(C, P)

    # Coral dynamics:
    #   r*C*(1 - C/K) = logistic growth toward carrying capacity K
    #   -alpha*P*C    = growth inhibition that increases with microplastics and coral cover
    dCdt = r * C * (1 - C / K) - alpha * P * C

    # Microplastics dynamics:
    #   +I            = constant input (pollution entering the system)
    #   -delta*P      = slow degradation/export
    #   -beta*C*P     = coral trapping/removal 
    dPdt = I - delta * P - beta * C * P

    return [dCdt, dPdt]


def coral_microplastics_with_allee(t, y, I, K, r, alpha, delta, beta, A):
    """Coral–microplastics ODE model WITH an Allee effect in coral growth. """
    C, P = y
    C, P = safe_nonnegative(C, P)

    # Coral dynamics with Allee effect:
    #   r*C*(1 - C/K)*(C/A - 1) = logistic growth modified to include a critical threshold A
    #   -alpha*P*C              = microplastics inhibition
    dCdt = r * C * (1 - C / K) * (C / A - 1.0) - alpha * P * C

    # Microplastics dynamics 
    dPdt = I - delta * P - beta * C * P

    return [dCdt, dPdt]

Microplastic concentrations are reported in physical units (particles m⁻³) and vary widely across sampling locations, which can lead to instability and poor parameter interpretability when used directly in differential equation models. To address this, microplastic concentrations are rescaled into a dimensionless variable $P$ by dividing by a representative high-value concentration. This concentration is defined here as the 90th percentile of observed data. This scaling allows model parameters to operate on comparable numerical scales and makes simulation results easier to interpret across regions and scenarios.

def scale_microplastics(concentration_series, quantile=0.90):
    """Scale raw microplastic concentrations into a dimensionless variable P."""
    
    # Convert the input data to a Series and compute the 90th percentile 
    P_scale = float(pd.Series(concentration_series).quantile(quantile))

    # Check that the scaling value is valid and positive.
    if not np.isfinite(P_scale) or P_scale <= 0:
        raise ValueError("P_scale is invalid; check microplastics data for non-positive values.")

    # Return the scaled microplastics concentration P and the scaling constant used 
    return concentration_series / P_scale, P_scale

compute_region_coral_cover() extracts a data driven coral starting condition $C0$ from the most recent AIMS year and converts it into a fraction that can be used for the logistic growth model. compute_region_microplastics_scaled() builds a dimensionless microplastics starting condition $P0$ by scaling raw concentrations using a quantile. Finally, build_initial_conditions() ensures that the model only simulate regions where there is both coral and microplastics data.

def compute_region_coral_cover(coral_df):
    """Compute region-specific initial coral cover values (C0)."""
    # Identify the most recent year in the dataset
    latest_year = coral_df["YEAR_CODE"].max()

    # Subset to the latest year and make a copy 
    latest = coral_df.loc[coral_df["YEAR_CODE"] == latest_year].copy()

    # Assign a GBR region to each row based on latitude
    latest.loc[:, "GBR_region"] = latest["LATITUDE"].apply(assign_gbr_region)

    # Mean coral cover per region
    region_coral_fraction = latest.groupby("GBR_region")["COVER"].mean() / 100.0

    # Sort the index 
    return region_coral_fraction.sort_index()


def compute_region_microplastics_scaled(micro_df, quantile=0.90):
    """Compute region-specific initial microplastic values (P0), scaled to be dimensionless."""
    # Compute scaling constant from the raw concentration distribution
    P_scale = float(micro_df["Microplastics"].quantile(quantile))

    # Validate scaling constant
    if not np.isfinite(P_scale) or P_scale <= 0:
        raise ValueError("P_scale is invalid; check microplastics data for non-positive or missing values.")

    # Make copy
    micro = micro_df.copy()

    # Assign GBR regions using the same latitude
    micro.loc[:, "GBR_region"] = micro["Latitude"].apply(assign_gbr_region)

    # Create a dimensionless microplastics variable
    micro.loc[:, "P_scaled"] = micro["Microplastics"] / P_scale

    # Compute mean scaled microplastics per region
    region_scaled = micro.groupby("GBR_region")["P_scaled"].mean().sort_index()

    return region_scaled, P_scale


def build_initial_conditions(region_coral, region_micro_scaled):
    """ Build region-specific initial conditions y0 = [C0, P0] for the ODE solver. """
    # Identify overlapping regions across both datasets
    common_regions = sorted(set(region_coral.index) & set(region_micro_scaled.index))

    # If there is no overlap, the model can't build initial conditions
    if len(common_regions) == 0:
        raise ValueError("No overlapping regions between coral and microplastics data.")

    # Build y0 dictionary 
    y0_by_region = {
        reg: [float(region_coral.loc[reg]), float(region_micro_scaled.loc[reg])]
        for reg in common_regions}
    return y0_by_region

This function provides reusable and easily accessible set up around scipy.integrate.solve_ivp to run the coral microplastics model for any region and parameter set. By passing the ODE system, initial conditions, input rate, and parameters as arguments, the function keeps the numerical solver separate from the ecological model itself.

def run_simulation(model_fun, y0, I, params, t_span, t_eval):
    """Run a numerical simulation of the coral–microplastics ODE model for a single region 
    and a single microplastic input rate."""

    # Solve the system of differential equations 
    sol = solve_ivp(
        # Wrap the model function so I and parameters are passed cleanly
        fun=lambda t, y: model_fun(t, y, I, **params),
        t_span=t_span,
        # Initial coral cover and microplastic concentration
        y0=y0,
        t_eval=t_eval,
        method="RK45",

        # tolerances for accuracy
        rtol=1e-6,
        atol=1e-9)
    return sol

def plot_region_results(solutions_by_region, labels, K, A=None, title=""):
    """ Plot ODE results for multiple GBR regions."""
    # Convert dict keys into a stable list of region names (plot order)
    regions = list(solutions_by_region.keys())
    n_regions = len(regions)

    # Create a grid with one row per region and two columns:
    # left = coral cover C(t), right = microplastics P(t)
    fig, axes = plt.subplots(
        n_regions, 2,
        figsize=(14, 4 * n_regions),
        sharex=True)
    fig.suptitle(title, y=1.02)

    # If there's only one region, matplotlib returns axes as shape (2,)
    if n_regions == 1:
        axes = np.array([axes])

    for row, region in enumerate(regions):
        sols = solutions_by_region[region]

        # If passed a single solution instead of a list, wrap it.
        if not isinstance(sols, (list, tuple)):
            sols = [sols]

        # Ensure we have the right number of labels for the number of solutions.
        if (labels is None) or (len(labels) != len(sols)):
            scenario_labels = [f"Scenario {i+1}" for i in range(len(sols))]
        else:
            scenario_labels = labels

        # Plot each scenario for this region
        for sol, lab in zip(sols, scenario_labels):
            axes[row, 0].plot(sol.t, sol.y[0], label=lab)  # C(t)
            axes[row, 1].plot(sol.t, sol.y[1], label=lab)  # P(t)

        # Reference lines on coral plot
        axes[row, 0].axhline(K, linestyle="--", alpha=0.5)
        if A is not None:
            axes[row, 0].axhline(A, linestyle=":", alpha=0.7)

        # Axis labels + grids
        axes[row, 0].set_ylabel(f"{region}\nC(t)")
        axes[row, 1].set_ylabel("P(t)")
        axes[row, 0].grid(True)
        axes[row, 1].grid(True)

    # Legend
    axes[0, 0].legend()

    # Shared x-label on bottom 
    axes[-1, 0].set_xlabel("Time (years)")
    axes[-1, 1].set_xlabel("Time (years)")

    # Column titles
    axes[0, 0].set_title("Coral cover")
    axes[0, 1].set_title("Microplastics")

    plt.tight_layout()
    plt.show()

This section of the project simulates coral–microplastic dynamics under a constant microplastic input rate using a coupled system of differential equations. The model is run separately for different Great Barrier Reef regions, with region-specific initial coral cover and microplastic concentrations estimated directly from data. Although the microplastic input rate $I$ is constant across regions, microplastic concentrations can increase or decrease differently because the removal of microplastics depends on local coral cover through the $−{\beta}CP$ term in the model. Regions with higher coral cover remove microplastics more readily, while regions with lower coral cover allow microplastics to accumulate. The plots show coral cover declining over time due to stress and microplastic exposure, while microplastic concentration may either increase or decrease depending on coral-mediated removal. Together, these results highlight how feedbacks between coral health and pollution can lead to region-specific outcomes, even under identical external forcing.
